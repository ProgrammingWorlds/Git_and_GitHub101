دليل حل المشاكل

«git» غير معروف

السبب: Git غير مثبت أو فُتحت الطرفية قبل التثبيت.

الحل: ثبّت Git for Windows وأغلق Git Bash أو VS Code وافتحه من جديد ثم نفّذ git --version.

Author identity unknown

السبب: لم يُضبط user.name وuser.email.

الحل: نفّذ git config --global user.name "Your Name" وuser.email "you@example.com".

fatal: not a git repository

السبب: أنت خارج مجلد المشروع أو لم تنفّذ git init.

الحل: انتقل بـ cd إلى مجلد المشروع، ونفّذ git init إن كان مشروعًا جديدًا.

nothing to commit

السبب: لا تغييرات أو لم تُجهَّز.

الحل: عدّل ملفًا أو نفّذ git add أولًا وتحقق من git status.

remote origin already exists

السبب: أضفت origin سابقًا.

الحل: استخدم git remote -v وعدّل بـ git remote set-url origin URL.

Repository not found

السبب: الرابط خاطئ أو دخلت بحساب آخر.

الحل: تحقق من الرابط في GitHub وسجّل الدخول من جديد عبر Git Credential Manager.

Authentication failed

السبب: بيانات دخول قديمة أو خاطئة.

الحل: افتح Credential Manager في Windows واحذف إدخالات github.com ثم ارفع وسجّل الدخول.

failed to push some refs (fetch first)

السبب: عند GitHub commits لا تملكها.

الحل: نفّذ git pull وحلّ التعارضات إن وُجدت ثم git push.

Your local changes would be overwritten

السبب: تعديلات غير محفوظة تمنع التبديل أو السحب.

الحل: احفظ commit أو نفّذ git stash ثم أعد المحاولة.

CONFLICT (content)

السبب: تغييران على الأسطر نفسها.

الحل: عدّل الملف وأزل العلامات ثم git add وgit commit. أو git merge --abort.

detached HEAD

السبب: انتقلت إلى commit لا فرع.

الحل: git switch main أو git switch -c name للاحتفاظ بالعمل.

رفض الرفع إلى main (محمي)

السبب: الفرع محمي.

الحل: ارفع فرع ميزة وافتح pull request.

حفظت سرًّا في commit

السبب: كلمة سر أو token في التاريخ.

الحل: ألغِه أو بدّله أولًا ثم أزله من الكود وأضفه إلى .gitignore.

.gitignore لا يعمل

السبب: الملف مُتتبَّع أصلًا.

الحل: git rm --cached FILE ثم commit.

GitHub Pages يعرض 404

السبب: لم يُفعَّل أو مجلد خاطئ أو لا index.html في الجذر.

الحل: Settings ← Pages: main / root؛ انتظر دقائق؛ تحقق من index.html.

VS Code لا يعرض تغييرات Source Control

السبب: فتحت مجلدًا خاطئًا.

الحل: File ← Open Folder واختر المجلد الذي فيه .git.
