Troubleshooting guide

“git” is not recognized

Cause: Git is not installed or the terminal was opened before installing.

Fix: Install Git for Windows, close and reopen Git Bash or VS Code, then run git --version.

Author identity unknown

Cause: user.name and user.email are not set.

Fix: Run git config --global user.name "Your Name" and user.email "you@example.com".

fatal: not a git repository

Cause: You are outside the project folder or never ran git init.

Fix: cd into the project folder; run git init if it is a new project.

nothing to commit

Cause: No changes, or changes are not staged.

Fix: Edit a file or run git add first; check git status.

remote origin already exists

Cause: You already added origin.

Fix: Use git remote -v; fix with git remote set-url origin URL.

Repository not found

Cause: Wrong URL, or you are signed in to another account.

Fix: Check the URL on GitHub; sign in again through Git Credential Manager.

Authentication failed

Cause: Old or wrong saved credentials.

Fix: Open Windows Credential Manager, remove github.com entries, then push again and sign in.

failed to push some refs (fetch first)

Cause: GitHub has commits you do not have.

Fix: git pull, resolve conflicts if any, then git push.

Your local changes would be overwritten

Cause: Uncommitted edits block a switch or pull.

Fix: Commit or git stash first, then retry.

CONFLICT (content)

Cause: Two changes touched the same lines.

Fix: Edit the file, remove markers, git add, git commit. Or git merge --abort.

detached HEAD

Cause: You checked out a commit, not a branch.

Fix: git switch main, or git switch -c name to keep the work.

Push rejected on main (protected)

Cause: The branch is protected.

Fix: Push a feature branch and open a pull request.

I committed a secret

Cause: A password or token is in history.

Fix: Revoke or rotate it first; then remove it from the code and add it to .gitignore.

.gitignore does not work

Cause: The file was already tracked.

Fix: git rm --cached FILE and commit.

GitHub Pages shows 404

Cause: Pages not enabled yet, wrong folder, or no index.html in root.

Fix: Settings → Pages: main / root; wait a few minutes; check index.html.

VS Code does not show Source Control changes

Cause: Opened the wrong folder.

Fix: File → Open Folder and choose the folder that contains .git.
