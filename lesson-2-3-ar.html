الوحدة 02 · الدرس 2.3

إعداد Git لأول مرة

First-time Git configuration

أهداف التعلم

  • أن تضبط الاسم والبريد والفرع الافتراضي.
  • أن تتحقق من إعداداتك.
  • أن تشرح الإعداد العام والمحلي.
  • أن تفرّق بين هوية الـ commit وتسجيل الدخول إلى GitHub.

المتطلبات المسبقة

الدرسان 2.1 و2.2.

مقدمة

كل commit يسجّل من صنعه. لا يستطيع Git تخمين ذلك، فتضبطه مرة واحدة.

الشرح

اضبط هويتك. نفّذ أول أمرين أدناه ببياناتك. استخدم بريد حساب GitHub، أو عنوان noreply الذي يعرضه GitHub في Settings ← Emails.

الفرع الافتراضي. الأمر الثالث يجعل المستودعات الجديدة تبدأ بفرع اسمه main.

تحقّق. الأمر git config --global --list يطبع كل الإعدادات العامة.

عام ومحلي. الخيار --global يحفظ في ملف المستخدم ويسري على كل المستودعات. وبدونه، داخل مستودع، يكون الإعداد محليًا ويسري هناك فقط. والمحلي يتغلب على العام.

الهوية مقابل الدخول. الاسم والبريد مجرد وسوم على الـ commits، ولا يثبتان من أنت. أما المصادقة (دخول HTTPS أو مفتاح SSH) فهي ما يسمح لك بالرفع. ويمكنك استخدام SSH لاحقًا: الأمر ssh-keygen -t ed25519 -C "you@example.com" ينشئ زوج مفاتيح، ونكمله في الوحدة 5.

تشبيه من الحياة

الاسم والبريد توقيع على رسالة. يستطيع أي شخص كتابة توقيع، لكن مفتاحك وحده يفتح صندوق البريد.

مخطط توضيحي

الأوامر

git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git config --global init.defaultBranch main
git config --global --list

الخيارات: --global إعداد على مستوى المستخدم؛ --list عرض الإعدادات.

أخطاء شائعة وحلولها

كتابة علامات الاقتباس بشكل خاطئ.استخدم علامات اقتباس مستقيمة حول الأسماء التي فيها مسافات.
استخدام بريد مختلف عن GitHub.قد لا ترتبط الـ commits بملفك. استخدم بريد GitHub.
الخلط بين config وتسجيل الدخول.الإعداد يضع وسمًا على الـ commits فقط. الدخول أمر منفصل.

تمرين عملي

نفّذ الأوامر الأربعة ببياناتك، ثم تأكد أن الخرج يطابق ما كتبته.

النتيجة المتوقعة

تعرض القائمة user.name وuser.email وinit.defaultbranch=main.

اختبر فهمك

1. ماذا يفعل user.name؟
2. أيهما يتغلب، المحلي أم العام؟
3. هل user.email يوثّق هويتك؟

الإجابات

  • يضع اسمك على commits — يُوضع على كل commit.
  • المحلي — الإعداد المحلي يتغلب على العام في ذلك المستودع.
  • لا، المصادقة أمر منفصل — هو وسم. دخول HTTPS أو مفتاح SSH هو الذي يوثّق.

الخلاصة

ضبطت اسمك وبريدك والفرع الافتراضي، وتحققت منها، وعرفت أن هوية الـ commit ليست تسجيل الدخول إلى GitHub.
