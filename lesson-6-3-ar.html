الفروع والتاريخ في VS Code

Branches and history in VS Code

أهداف التعلم

  • أن تقرأ مؤشر الفرع.
  • أن تنشئ فروعًا وتنتقل بينها.
  • أن تعرض تاريخ ملف.
  • أن تعرف أين تقع التعارضات وتسجيل الدخول.
  • أن تفرّق بين Git المدمج وGitLens.

المتطلبات المسبقة

الدرس 6.2.

مقدمة

الفروع مشروحة بعمق في الوحدة 7. هنا تتعلم فقط أين توجد أدواتها.

الشرح

مؤشر الفرع. أسفل يسار النافذة يظهر الفرع الحالي مثل main.

التبديل أو الإنشاء. اضغطه فتفتح قائمة في الأعلى: اختر فرعًا للانتقال، أو اختر Create new branch… واكتب اسمًا مثل feature/homepage.

التاريخ. في عرض Explorer افتح لوحة Timeline في الأسفل لترى الـ commits التي غيّرت الملف المفتوح. اضغط واحدًا لتقارن. وتقدم الإصدارات الحديثة أيضًا رسمًا للـ commits داخل Source Control.

مقارنة التغييرات. اضغط أي ملف متغير في Source Control لترى القديم والجديد جنبًا إلى جنب.

التعارضات. إن حدث تعارض عند الدمج تظهر الملفات تحت Merge Changes. افتح ملفًا واستخدم Resolve in Merge Editor. الوحدة 7 تعلّم هذا.

Sync Changes يجلب ثم يرفع بضغطة واحدة.

تسجيل الدخول إلى GitHub. أيقونة Accounts أسفل الشريط الأيسر تبيّن من سجّل دخوله وتتيح الدخول والخروج.

GitLens إضافة اختيارية تضيف blame وتاريخًا أغنى وغير ذلك. لا نحتاجها في هذه الدورة. كل ما سبق مدمج.

تشبيه من الحياة

شريط الحالة لافتة طريق: يخبرك دائمًا على أي طريق (فرع) أنت.

مخطط توضيحي

الأوامر

المعادلات: git branch يعرض الفرع؛ git switch -c feature/homepage ينشئ فرعًا؛ git switch main ينتقل.

أخطاء شائعة وحلولها

التعديل على main بالخطأ.انظر أسفل اليسار قبل أن تبدأ.
منع الانتقال بسبب تغييرات.احفظ تغييراتك في commit أولًا.
تثبيت GitLens والضياع.تعلّم الأدوات المدمجة أولًا.

تمرين عملي

أنشئ فرعًا feature/homepage من شريط الحالة، ثم عد إلى main.
