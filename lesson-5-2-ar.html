git remote وgit push

git remote and git push

أهداف التعلم

  • أن تنشئ مستودعًا فارغًا على GitHub.
  • أن تربطه بـ git remote add.
  • أن ترفع بـ git push -u origin main.
  • أن تشرح -u والـ upstream.
  • أن تصلح أخطاء push الشائعة.

المتطلبات المسبقة

الدرس 5.1 وcommit واحد على الأقل.

مقدمة

هذه الخطوة التي يظهر فيها عملك لأول مرة على الإنترنت.

الشرح

أنشئ المستودع. في GitHub اختر New. سمّه my-first-project. اترك «Add a README» وبقية الملفات غير محددة ليبدأ المستودع فارغًا. أنشئه وانسخ رابط HTTPS.

الأمر git remote add origin <URL> يحفظ الـ remote باسم origin. وgit remote -v يسرد الـ remotes (الشكل 1).

الأمر git branch -M main يعيد تسمية فرعك الحالي إلى main. هو آمن، ويضمن تطابق الاسم مع GitHub.

الأمر git push -u origin main يرفع فرع main إلى origin. والخيار -u يضبط الـ upstream: يخبر Git أن main المحلي مرتبط بـ origin/main. بعدها يكفي git push وحده.

الرفع الأول مقابل اللاحق. الرفع الأول يحتاج -u origin main. والرفعات اللاحقة هي git push فقط.

المصادقة. عند أول رفع تُفتح نافذة Git Credential Manager. سجّل دخولك إلى GitHub في المتصفح. يتذكره Git بعد ذلك.

تأكّد. حدّث صفحة المستودع: ملفاتك وcommits موجودة.

تشبيه من الحياة

git remote add يحفظ عنوان المكتبة. وgit push إرسال الطرد بالبريد. و-u يتذكر العنوان فتقول المرة القادمة «أرسله» فقط.

مخطط توضيحي

الأوامر

git remote add origin https://github.com/YOUR-USERNAME/my-first-project.git
git remote -v
git branch -M main
git push -u origin main
git push

الخيارات: -v قائمة مفصّلة؛ -M إعادة تسمية الفرع بالقوة؛ -u ضبط الـ upstream. استبدل YOUR-USERNAME باسمك.

أخطاء شائعة وحلولها

«remote origin already exists»استخدم git remote set-url origin <URL> لتغييره.
«Repository not found»تحقق من كتابة الرابط ومن أنك مسجّل بالحساب الصحيح.
«Authentication failed»سجّل دخولك مرة أخرى عبر نافذة المتصفح. لا تستخدم كلمة السر في الطرفية.
«rejected … non-fast-forward»في الـ remote commits ليست عندك. ستصلح هذا بـ pull في الوحدة 8.

تمرين عملي

أنشئ مستودع GitHub فارغًا، وأضف الـ remote، وارفع main.

النتيجة المتوقعة

يطبع Git «branch ‘main’ set up to track ‘origin/main’» ويعرض GitHub الـ commits الثلاثة والملفات الثلاثة.

اختبر فهمك

1. ماذا يفعل -u في git push -u؟
2. أي أمر يسرد الـ remotes؟
3. هل تصل الـ commits إلى GitHub بـ git commit؟

الإجابات

  • يضبط الفرع upstream — يربط main المحلي بـ origin/main.
  • git remote -v — git remote -v يعرض الأسماء والروابط.
  • لا، يجب أن تنفّذ push — الـ commit محلي، والـ push يرفع.

الخلاصة

أنشأت مستودع GitHub فارغًا، وربطته باسم origin، ورفعت main بـ -u. بعدها يكفيك git push.

مصطلحات أساسية

Upstreamالفرع البعيد الذي يتتبعه فرعك المحلي
git pushرفع الـ commits إلى remote
-uضبط الـ upstream أثناء الرفع
