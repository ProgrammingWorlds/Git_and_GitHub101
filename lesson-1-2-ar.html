Git مقابل GitHub مقابل VS Code

Git vs GitHub vs VS Code

أهداف التعلم

  • أن تعرّف Git وGitHub وVS Code بجملة لكل منها.
  • أن تشرح المستودع المحلي والمستودع البعيد.
  • أن تفرّق بين المستودع العام والخاص.

المتطلبات المسبقة

الدرس 1.1.

مقدمة

يستخدم المبتدئون كلمتي Git وGitHub وكأنهما شيء واحد. هما في الحقيقة أداتان مختلفتان، وVS Code ثالثتهما. ومعرفة الفرق تزيل معظم الحيرة في البداية.

الشرح

Git برنامج مجاني على جهازك يسجّل تاريخ ملفاتك، ويعمل دون إنترنت.

GitHub موقع يحفظ مشاريع Git على الإنترنت، ويضيف المشاركة والعمل الجماعي: نسخًا احتياطية، وقضايا (Issues)، وطلبات دمج (Pull Requests)، وصفحة تعريفية.

VS Code (Visual Studio Code) محرر أكواد فيه Git مدمج، فتستطيع التجهيز والحفظ والرفع بأزرار بدل الكتابة.

المستودع (Repository) هو مجلد المشروع مع تاريخ Git. نسختك هي المستودع المحلي، والنسخة على GitHub هي المستودع البعيد. والـ commit لقطة محفوظة واحدة، والفرع (branch) خط من الـ commits. ستدرس الفروع في الوحدة 7.

المستودعات العامة يراها أي شخص، والخاصة لا يراها إلا أنت ومن تدعوهم. لا تضع كلمات السر في أي منهما أبدًا.

تشبيه من الحياة

تأليف كتاب: VS Code طاولة الكتابة، وGit المحرّر الذي يحتفظ بكل مسودة، وGitHub المجلد المشترك على السحابة الذي يقرؤه فريقك.

مخطط توضيحي

الأوامر

لا توجد أوامر بعد. في الدرس 2.1 ستثبّت الأدوات وتشغّل git --version.

أخطاء شائعة وحلولها

الظن أن GitHub ضروري لاستخدام Git.Git يعمل وحده. GitHub اختياري لكنه مفيد جدًا للمشاركة.
الظن أن VS Code وGit شيء واحد.VS Code محرر فقط، ويعطيك أزرارًا لاستخدام Git.
جعل المستودع عامًا بالخطأ.تحقّق من إعداد الخصوصية قبل إنشاء المستودع أو نشره.

تمرين عملي

افتح github.com في المتصفح، ثم افتح أي مستودع عام. جد ثلاثة أشياء: نص README، وقائمة الملفات، واسم الفرع (غالبًا main).

النتيجة المتوقعة

تستطيع الإشارة إلى README وقائمة الملفات ومحدد الفرع في الصفحة. لم تحتج إلى حساب لهذا.

اختبر فهمك

1. أي أداة تحفظ مشروعك على الإنترنت؟
2. أين يوجد المستودع المحلي؟
3. من يرى المستودع الخاص؟

الإجابات

  • GitHub — GitHub يستضيف المستودعات البعيدة.
  • على جهازك — المستودع المحلي هو تاريخ المشروع المحفوظ على جهازك.
  • أنت ومن تدعوهم فقط — الخاص يعني أنه مرئي لك وللمتعاونين الذين تختارهم.

الخلاصة

Git يتتبّع التغييرات، وGitHub يستضيف المستودعات على الإنترنت، وVS Code محرر فيه أزرار Git. جهازك يحمل المستودع المحلي وGitHub يحمل البعيد.
