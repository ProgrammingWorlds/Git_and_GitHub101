الوحدة 05 · الدرس 5.3

استكشاف مستودع GitHub

Exploring a GitHub repository

أهداف التعلم

  • أن تجد الملفات والـ commits والفروع على GitHub.
  • أن تقرأ README على الصفحة.
  • أن تسمّي Issues وPull requests.
  • أن تجد الخصوصية والروابط.

المتطلبات المسبقة

الدرس 5.2.

مقدمة

صار لمشروعك المرفوع صفحة ويب. تعلّم أجزاءها لأنك ستستخدمها كل يوم.

الشرح

تبويب Code: الملفات والمجلدات، ومحدد الفرع (main)، وزر Code الأخضر مع رابط النسخ.

يظهر README تحت قائمة الملفات منسّقًا. هو الصفحة الأولى للمشروع.

Commits: اضغط أيقونة الساعة مع عدد الـ commits لترى كل commit مع الرسالة والمؤلف والتاريخ.

Branches: تسرد كل الفروع. ستنشئ المزيد في الوحدة 7.

Issues لتتبّع المهام والأخطاء. وPull requests لاقتراح تغييرات للمراجعة (الوحدة 9).

Settings تتحكم في الخصوصية (Public أو Private) والمتعاونين، ولاحقًا GitHub Pages. غيّر الخصوصية بحذر.

الروابط. عنوان الصفحة هو https://github.com/USER/REPO. ونسخته المنتهية بـ .git هي التي يستخدمها Git للنسخ والرفع.

تشبيه من الحياة

صفحة المستودع واجهة محل لمشروعك: الصفحة الأولى (README)، وقائمة البضاعة (الملفات)، وكتاب التاريخ (commits).

مخطط توضيحي

الأوامر

لا توجد أوامر Git هنا. تعمل في المتصفح.

أخطاء شائعة وحلولها

جعل المستودع عامًا بالخطأ.تحقق من الخصوصية في Settings.
تعديل الملفات على GitHub ونسيان النسخة المحلية.ستحتاج لاحقًا إلى pull لهذه التغييرات (الوحدة 8).
تجاهل README.اكتبه مبكرًا. هو أول ما يقرؤه الناس.

تمرين عملي

افتح مستودعك على GitHub. جد: قائمة الملفات، وعدد الـ commits، ومحدد الفرع، وREADME، وتبويب Settings.

النتيجة المتوقعة

تستطيع تحديد الخمسة وفتح قائمة الـ commits التي تعرض commits الثلاثة.

اختبر فهمك

1. أين ترى سجل الـ commits؟
2. لماذا تُستخدم Pull requests؟
3. أين تُضبط الخصوصية؟

الإجابات

  • رابط Commits في تبويب Code — عدد الـ commits يفتح التاريخ كاملًا.
  • لاقتراح تغييرات للمراجعة — بها تُراجَع التغييرات وتُدمج.
  • Settings — Settings فيها Public وPrivate.

الخلاصة

صفحة مستودع GitHub تعرض الكود والـ commits والفروع وREADME وissues وpull requests والإعدادات ومنها الخصوصية.

مصطلحات أساسية

Issueمهمة أو خطأ يُتتبَّع
Pull requestاقتراح لدمج تغييرات
