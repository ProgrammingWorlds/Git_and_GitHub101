الوحدة 04

المختبر العملي 4 · أنشئ ثلاثة commits وافحصها

  1. نفّذ git add index.html style.css ثم git commit -m "Add homepage".
  2. أضف السطر p { line-height: 1.6; } إلى style.css. افحص بـ git diff وجهّزه ثم git commit -m "Improve text spacing".
  3. أضف جملة واحدة إلى README.md. نفّذ git add README.md ثم git commit -m "Update README".
  4. نفّذ git log --oneline وgit show.
الفحصينجح إذا…
ثلاثة commitsgit log --oneline يعرض ثلاثة أسطر
الرسائلكل رسالة تبدأ بفعل وتصف التغيير
التجهيز الانتقائيكل commit يحتوي الملفات المقصودة فقط
حالة نظيفةgit status يقول «nothing to commit, working tree clean»
معيار التقييم: 4 فحوص من 4 = نجاح.

اختبار الوحدة 4 (علامة النجاح: 70%)

1. أي أمر يجهّز ملفًا واحدًا؟
2. ماذا يفعل git add .؟
3. أي أمر يحفظ التغييرات المجهّزة؟
4. كيف ترى التغييرات المجهّزة؟
5. ماذا تعني (HEAD -> main) في السجل؟

الإجابات

  • git add index.html — git add متبوعًا باسم الملف يجهّزه.
  • يجهّز التغييرات في المجلد الحالي — يجهّز ولا ينشئ commit ولا يرفع.
  • git commit -m "message" — الـ commit ينشئ اللقطة.
  • git diff --staged — الخيار --staged يقارن منطقة التجهيز بآخر commit.
  • أنت على أحدث commit في main — HEAD يحدد موقعك الحالي.
