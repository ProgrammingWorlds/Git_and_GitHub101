Understanding repositories

Prerequisites

Module 2 completed.

Introduction

You have heard the word “repository” many times. Here it gets a precise meaning, and you will see exactly what makes a folder special to Git.

Explanation

A repository (repo) is a project folder that Git is tracking, together with the full history of that project.

A normal folder is just files. It becomes a Git repository when you run git init inside it. Git then creates a hidden folder named .git.

The .git directory stores the commits, branches and settings of the repository. Your own files live next to it, not inside it. Never edit or delete .git by hand. Deleting it removes the history, although your files stay.

A local repository is the one on your computer. A remote repository is a copy on a server such as GitHub. You will connect them in Module 5.

To see hidden items in Windows, open File Explorer and choose View → Show → Hidden items.

Real-world analogy

A folder is a house. The .git folder is the archive of security-camera recordings: the house looks the same, but the archive remembers everything that happened inside.

Common mistakes and solutions

Deleting the .git folder.Your history is gone. Only do this if you truly want to stop using Git in that project.
Thinking .git is inside your project files.It is a hidden sibling of your files. Your files stay outside it.
Creating a repo inside another repo.Check you are in the right folder before git init.

Practical exercise

Turn on hidden items in File Explorer. Open your Documents folder and check that it does not contain a .git folder.

Expected result

You see no .git folder. Ordinary folders are not repositories until you initialize them (Lesson 3.2).

Knowledge check

1. What makes a folder a Git repository?
2. What does .git store?
3. Where is a remote repository?

Answers

  • A hidden .git folder inside it — git init creates .git, which holds the history.
  • Commits, branches and settings — It holds the repository data.
  • On a server such as GitHub — Remote means a copy hosted elsewhere.

Summary

A repository is a project folder plus its Git history, stored in the hidden .git folder. Local is on your computer, remote is on a server such as GitHub.
