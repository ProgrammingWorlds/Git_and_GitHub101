الوحدة 10 · الدرس 10.2

تعديل commit أو عكسه

Fix or revert a commit

أهداف التعلم

  • أن تعدّل آخر commit.
  • أن تعكس commit.
  • أن تختار بين amend وrevert.

المتطلبات المسبقة

الدرس 10.1.

مقدمة

أحيانًا يكون الخطأ داخل commit. والأداة الصحيحة تعتمد على أنك رفعته أم لا.

الشرح

لم يُرفع بعد. git commit --amend -m "Better message" يستبدل آخر commit. لإضافة ملف منسي نفّذ git add file أولًا ثم amend.

الـ amend يعيد كتابة الـ commit (يأخذ ID جديدًا). لا تعدّل commit قد يملكه غيرك.

رُفع أو شورك. git revert HEAD ينشئ commit جديدًا يلغي القديم. يبقى التاريخ صادقًا وآمنًا للجميع.

لعكس commit أقدم استخدم رقمه من git log --oneline: git revert 8d2e5b1.

قد يتعارض الـ revert؛ حلّه كما في الدرس 7.3 ونفّذ git revert --continue.

بعد الـ revert نفّذ git push كالمعتاد.

تشبيه من الحياة

الـ amend تصحيح خطأ إملائي في رسالة قبل بريدها. والـ revert إرسال رسالة ثانية تلغي الأولى.

مخطط توضيحي

الأوامر

git commit --amend -m "msg"
git revert HEAD
git revert COMMIT-ID

الشكل 1 يعرض الاثنين.

أخطاء شائعة وحلولها

amend بعد الرفع.استخدم revert؛ الـ amend يحتاج force push وهو خطر.
عكس ID خاطئ.تحقق من git log --oneline.
توقّع أن revert يحذف التاريخ.هو يضيف commit جديدًا.

تمرين عملي

نفّذ commit برسالة فيها خطأ إملائي وعدّله بـ amend. ثم اعكس آخر commit.

النتيجة المتوقعة

يعرض git log --oneline commit الـ revert في الأعلى.

اختبر فهمك

1. أيهما آمن للـ commits المرفوعة؟
2. ماذا يغيّر amend؟
3. هل يحذف revert التاريخ؟

الإجابات

  • git revert — يضيف commit جديدًا.
  • آخر commit — يعيد كتابته.
  • لا — يضيف commit يلغي.

الخلاصة

amend قبل الرفع، وrevert بعد الرفع.

مصطلحات أساسية

amendاستبدال آخر commit
revertcommit يلغي آخر
commit IDرمز قصير مثل 8d2e5b1
