الوحدة 07 · الدرس 7.2

إنشاء الفروع ودمجها

Creating and merging branches

أهداف التعلم

  • أن تعرض الفروع وتنشئها وتنتقل بينها.
  • أن تدمج فرعًا في main.
  • أن تحذف فرعًا مدموجًا.

المتطلبات المسبقة

الدرس 7.1 وشجرة عمل نظيفة.

مقدمة

الآن تنشئ فرعًا وتعمل عليه ثم تعيده.

الشرح

git branch يعرض الفروع المحلية. النجمة تدل على الحالي.

git switch -c feature/homepage ينشئ الفرع وينتقل إليه. الخيار -c يعني «أنشئ».

عدّل index.html ثم git add index.html وgit commit -m "Add welcome section". يقع الـ commit على فرع الميزة فقط.

git switch main يعيدك إلى main. يختفي تعديلك من المجلد لأن main لا يملكه بعد.

git merge feature/homepage يجلب الـ commits إلى main. وإن لم يتغير main منذ تفرّعت فإن Git يحرّك وسم main إلى الأمام فقط: Fast-forward. وإن تغير الاثنان ينشئ Git commit دمج.

git branch -d feature/homepage يحذف وسم الفرع بعد الدمج. الخيار -d يرفض إن لم يُدمج، وهذا يحميك.

لمشاركة الفرع: git push -u origin feature/homepage.

تشبيه من الحياة

التبديل بين الفروع كتغيير الفيلم في الكاميرا: الكاميرا (مجلدك) باقية، والصورة تتغير.

مخطط توضيحي

الأوامر

git branch
git switch -c feature/homepage
git switch main
git merge feature/homepage
git branch -d feature/homepage

الخيارات: -c إنشاء؛ -d حذف إن كان مدموجًا. الشكل 1 يعرض الدمج والتنظيف.

أخطاء شائعة وحلولها

«Your local changes would be overwritten»احفظ تغييراتك في commit قبل التبديل.
الدمج في الفرع الخطأ.انتقل أولًا إلى الفرع الذي يجب أن يستقبل العمل.
«not fully merged» عند الحذفادمج أولًا، أو تأكد أنك تريد فعلًا -D (إجباري).

تمرين عملي

أنشئ feature/homepage وأضف فقرة ترحيب واحفظها في commit وانتقل إلى main وادمج واحذف الفرع.

النتيجة المتوقعة

يحتوي main الفقرة، وgit branch يعرض main فقط.

اختبر فهمك

1. أي أمر ينشئ فرعًا وينتقل إليه؟
2. ما هو Fast-forward؟
3. أي فرع يستقبل العمل في الدمج؟

الإجابات

  • git switch -c name — الخيار -c ينشئ الفرع.
  • يحرّك Git الوسم للأمام دون commit دمج — يحدث عندما لا يتفرّع main.
  • الذي أنت عليه — تدمج في الفرع الحالي.

الخلاصة

أنشئ فرعًا بـ switch -c، واحفظ عليه، وانتقل إلى main، وادمج، ثم احذف الفرع.
