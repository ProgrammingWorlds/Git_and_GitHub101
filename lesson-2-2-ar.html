الوحدة 02 · الدرس 2.2

إنشاء حساب GitHub

Creating your GitHub account

أهداف التعلم

  • أن تنشئ حساب GitHub وتوثّقه.
  • أن تتعرف على لوحة التحكم.
  • أن تحمي الحساب بالمصادقة الثنائية.
  • أن تسمّي طرق تسجيل دخول Git إلى GitHub.

المتطلبات المسبقة

الدرس 2.1 وبريد إلكتروني تستطيع فتحه.

مقدمة

حساب GitHub هويتك على الإنترنت. مشاريعك وتاريخك ومعرض أعمالك المستقبلي كلها هناك، لذلك نحميه منذ اليوم الأول.

الشرح

إنشاء الحساب. افتح github.com واختر Sign up. أدخل بريدك وكلمة سر قوية واسم مستخدم. اختر اسمًا تفتخر بعرضه على صاحب عمل.

توثيق البريد. يرسل GitHub رمزًا إلى بريدك. أدخله لإكمال التسجيل. وقد يُطلب منك حل لغز قصير.

لوحة التحكم. بعد الدخول ترى مستودعاتك ونشاطك واقتراحات. صورتك (أعلى اليمين) تفتح قائمة فيها Your profile وYour repositories وSettings.

الملف الشخصي. أضف صورة ونبذة قصيرة، ولا تكتب فيها معلومات خاصة لا تريدها علنية.

الأمان. استخدم كلمة سر فريدة في مدير كلمات المرور. من Settings ← Password and authentication فعّل المصادقة الثنائية (2FA) بتطبيق مصادقة، واحفظ رموز الاسترداد في مكان آمن.

كيف يسجّل Git دخوله. عبر HTTPS يطلب Git حساب GitHub من نافذة تسجيل دخول ويحفظه في Git Credential Manager (يأتي مع Git لويندوز). وعبر SSH تضيف زوج مفاتيح إلى حسابك. لا تستخدم كلمة سر GitHub ككلمة سر لـ Git في الطرفية. ستجهّز طريقة في الوحدة 5.

تشبيه من الحياة

حسابك كحساب مصرفي لكودك: كلمة سر قوية وقفل ثانٍ (2FA) يبقيانه لك.

مخطط توضيحي

الأوامر

لا توجد أوامر Git هنا. كل الخطوات في المتصفح.

أخطاء شائعة وحلولها

ضياع رموز استرداد 2FA.احفظها في مدير كلمات المرور أو اطبعها.
استخدام بريد خاص في commits عامة.لاحقًا تستطيع استخدام عنوان noreply من GitHub (الدرس 2.3).
اختيار اسم مستخدم للمزاح.اختر اسمًا مهنيًا، فهو جزء من روابطك.

تمرين عملي

أنشئ حسابك، ووثّق البريد، وأضف صورة، وفعّل 2FA.

النتيجة المتوقعة

تستطيع فتح ملفك على github.com/your-username وتظهر 2FA مفعّلة في Settings.

اختبر فهمك

1. لماذا نفعّل 2FA؟
2. أين تعيش مشاريعك على الإنترنت؟
3. اذكر طريقة يسجّل بها Git دخوله إلى GitHub.

الإجابات

  • فحص ثانٍ يحمي الحساب — 2FA تمنع الدخول بكلمة سر مسروقة وحدها.
  • GitHub — GitHub يستضيف مستودعاتك البعيدة.
  • مفاتيح SSH — HTTPS مع Credential Manager ومفاتيح SSH هما الطريقتان الشائعتان.

الخلاصة

أنشأت حساب GitHub وحميته، وعرفت طريقتي الدخول التي يستخدمها Git: HTTPS وSSH.

مصطلحات أساسية

HTTPS / SSHطريقتان يتصل بهما Git مع GitHub
لوحة التحكم (Dashboard)صفحتك الرئيسية في GitHub
