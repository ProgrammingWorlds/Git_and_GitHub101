مراجعة سجل Git

Reviewing Git history

أهداف التعلم

  • أن تقرأ قائمة الـ commits بـ git log.
  • أن تقارن التغييرات بـ git diff وgit diff --staged.
  • أن تفحص commit بـ git show.

المتطلبات المسبقة

الدرس 4.2.

مقدمة

لا يفيد التاريخ إلا إذا استطعت قراءته. هذه الأوامر تعرض ما حدث ومتى.

الشرح

git log يسرد الـ commits من الأحدث إلى الأقدم. يعرض كل بند الـ hash الكامل والمؤلف والتاريخ والرسالة. وإن طالت القائمة فتح Git عارضًا: اضغط q للخروج منه.

git log --oneline يعرض سطرًا قصيرًا لكل commit: hash مختصر والرسالة. والعلامة (HEAD -> main) تبيّن أين أنت الآن.

git diff يعرض التغييرات التي أجريتها لكنك لم تجهّزها. وgit diff --staged يعرض التغييرات المجهّزة للـ commit القادم. الأسطر التي تبدأ بـ + أُضيفت، والتي تبدأ بـ - أُزيلت.

git show يعرض آخر commit مع تغييراته. وgit show 3f2a9c1 يعرض commit تختاره.

git status يبقى فحصك الأول: يخبرك بما تفعله بعد ذلك.

تشبيه من الحياة

git log سجل الرحلة في السفينة. وgit diff يقارن صفحة اليوم بما كُتب سابقًا.

مخطط توضيحي

الأوامر

git log
git log --oneline
git diff
git diff --staged
git show
git status

الشكل 1 يعرض git log --oneline بعد ثلاثة commits.

أخطاء شائعة وحلولها

العالق داخل git log.اضغط q للخروج من العارض.
توقع أن يعرض git diff التغييرات المجهّزة.استخدم git diff --staged لها.
نسخ hash كامل يدويًا.يكفي أول 7 أحرف.

تمرين عملي

عدّل README.md ونفّذ git diff. جهّزه ونفّذ git diff --staged. ثم نفّذ git log --oneline.

النتيجة المتوقعة

يعرض أول diff أسطرك المضافة بعلامة +. وبعد التجهيز لا يعرضها إلا --staged. ويسرد السجل commits التي أنشأتها.

اختبر فهمك

1. كيف تخرج من عارض git log؟
2. أي أمر يعرض التغييرات غير المجهّزة؟
3. ماذا يعرض git log --oneline؟

الإجابات

  • بالضغط على q — الحرف q يغلق العارض.
  • git diff — git diff يقارن ملفات عملك بمنطقة التجهيز.
  • سطرًا قصيرًا لكل commit — hash مختصر والرسالة لكل commit.

الخلاصة

git log يسرد التاريخ، وgit diff وgit diff --staged يقارنان التغييرات، وgit show يفحص commit واحدًا.
