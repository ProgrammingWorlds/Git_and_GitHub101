MODULE 07 · LESSON 7.2

Creating and merging branches

إنشاء الفروع ودمجها

Learning objectives

  • List, create and switch branches.
  • Merge a branch into main.
  • Delete a merged branch.

Prerequisites

Lesson 7.1 and a clean working tree.

Introduction

Now you create a branch, do some work, and bring it back.

Explanation

git branch lists local branches. The star marks the current one.

git switch -c feature/homepage creates the branch and switches to it. -c means “create”.

Edit index.html, then git add index.html and git commit -m "Add welcome section". The commit lands on the feature branch only.

git switch main returns to main. Your edit disappears from the folder because main does not have it yet.

git merge feature/homepage brings the commits into main. If main has not changed since you branched, Git just moves the main label forward: Fast-forward. If both changed, Git creates a merge commit.

git branch -d feature/homepage deletes the branch label after merging. -d refuses if it is not merged, which protects you.

To share the branch: git push -u origin feature/homepage.

Real-world analogy

Switching branches is changing the film in a camera: the camera (your folder) stays, the picture it shows changes.

Diagram

Commands

git branch
git switch -c feature/homepage
git switch main
git merge feature/homepage
git branch -d feature/homepage

Options: -c create; -d delete if merged. Figure 1 shows the merge and clean-up.

Common mistakes and solutions

“Your local changes would be overwritten”Commit your changes before switching.
Merging into the wrong branch.Switch to the branch that should receive the work first.
“not fully merged” on deleteMerge first, or confirm you really want -D (force).

Practical exercise

Create feature/homepage, add a welcome paragraph, commit, switch to main, merge, and delete the branch.

Expected result

main contains the paragraph and git branch lists only main.

Knowledge check

1. Which command creates and switches?
2. What is Fast-forward?
3. Which branch receives the work in a merge?

Answers

  • git switch -c name — -c creates the branch.
  • Git moves the label ahead without a merge commit — Happens when main has not diverged.
  • The one you are on — Merge into the current branch.

Summary

Create a branch with switch -c, commit on it, switch to main, merge, then delete the branch.
