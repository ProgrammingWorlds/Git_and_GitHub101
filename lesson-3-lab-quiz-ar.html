الإجابات

  • git init — الأمر git init يهيّئ مستودعًا.
  • تاريخ المستودع وإعداداته — هو قاعدة بيانات المستودع.
  • الفرع الحالي — أول سطر يسمّي الفرع.
  • غير متتبَّع — لم يتتبّعه Git بعد.
  • لأن Git لا يرى إلا التغييرات المحفوظة — التعديلات غير المحفوظة ليست على القرص.
