MODULE 03 · LESSON 3.2

git init and git status

git init وgit status

Learning objectives

  • Create a folder and enter it from the terminal.
  • Initialize a repository with git init.
  • Read the output of git status.

Prerequisites

Lesson 3.1 and a configured Git (Lesson 2.3).

Introduction

Two commands begin every Git project: git init creates the repository, and git status tells you what Git sees. You will run git status hundreds of times.

Explanation

mkdir my-first-project makes a new folder. cd my-first-project moves into it. Choose a location such as Documents. Do not use a folder that already holds other projects.

git init turns the current folder into a repository. Git answers “Initialized empty Git repository in …/.git/”. Running it again is harmless: Git says it reinitialized.

git status shows the branch, whether there are commits, and which files are untracked, modified or staged.

In the output, On branch main is the current branch. No commits yet means the history is empty. nothing to commit means Git sees no files yet.

Real-world analogy

git init is switching on the recorder. git status is asking the recorder what it currently sees.

Common mistakes and solutions

“fatal: not a git repository”You are outside a repository. Use cd to enter the project folder, or run git init first.
Running git init in the wrong folder.Run pwd to see where you are before you initialize.
Typing the folder name with spaces.Use names without spaces, such as my-first-project.

Practical exercise

Create my-first-project, initialize it, and run git status.

Expected result

Git reports an empty repository on branch main with no commits yet.

Knowledge check

1. Which command creates a repository?
2. What does “No commits yet” mean?
3. Which command shows what Git sees?

Answers

  • git init — git init initializes a repository.
  • The history is empty — No commit has been made.
  • git status — git status reports the working state.

Summary

You created a folder, ran git init to make it a repository, and read the result of git status.
