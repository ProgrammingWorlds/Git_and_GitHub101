MODULE 12

Capstone lab · Portfolio website with Git and GitHub

Build the project from Lessons 12.1–12.3. Starter files are in final-project/starter; a sample solution is in final-project/solution.

  1. Create the repository and push the skeleton.
  2. Build Home, About, Projects and Contact on separate branches.
  3. Open and merge at least two pull requests.
  4. Add README.md and .gitignore.
  5. Publish with GitHub Pages.
  6. Submit both URLs.

Module 12 quiz (pass mark: 70%)

1. What do you submit?
2. Which GitHub setting publishes the site?
3. Where should work be done?
4. A 404 on the live URL — first check?
5. What must never be committed?

Answers

  • Repository URL and live URL — Plus a short note.
  • Settings → Pages — Choose main / root.
  • On branches, merged by PR — Team workflow.
  • Branch, folder and index.html in root — Also wait a few minutes.
  • Secrets and tokens — Keep them out.
