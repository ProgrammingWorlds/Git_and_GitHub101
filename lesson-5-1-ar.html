الوحدة 05 · الدرس 5.1

المستودع المحلي مقابل البعيد

Local vs remote repositories

أهداف التعلم

  • أن تشرح ما هو مستودع GitHub.
  • أن تقرأ رابط مستودع بعيد.
  • أن تشرح معنى origin.
  • أن تفرّق بين main وorigin/main.
  • أن تفرّق بين روابط HTTPS وSSH.

المتطلبات المسبقة

الوحدة 4 وحساب GitHub.

مقدمة

حتى الآن تعيش تواريخك على جهازك فقط. يحفظ GitHub نسخة ثانية على الإنترنت. يشرح هذا الدرس كيف ترتبط النسختان قبل أن تربطهما.

الشرح

مستودع GitHub هو النسخة البعيدة من مشروعك. يخزّن الـ commits نفسها التي عندك محليًا، ويضيف صفحة ويب وأدوات مشاركة وعمل جماعي.

الـ remote إشارة مرجعية محفوظة إلى مستودع آخر، ورابطه (URL) يقول أين يوجد. صيغة HTTPS هي https://github.com/USER/REPO.git، وصيغة SSH هي git@github.com:USER/REPO.git.

origin مجرد اسم. جرت العادة أن يسمي Git الـ remote الرئيسي origin. تستطيع تسميته بغير ذلك لكن الجميع يستخدم origin.

الفروع. main فرعك المحلي. وorigin/main نسخة جهازك المتذكَّرة من فرع main البعيد (remote-tracking branch). لا يتحدث إلا عند push أو fetch أو pull.

HTTPS أم SSH؟ HTTPS أبسط للمبتدئين: يسجّل Git Credential Manager دخولك عبر المتصفح. أما SSH فيستخدم زوج مفاتيح ولا يسأل عن كلمة سر بعد الإعداد. هذه الدورة تستخدم HTTPS.

تشبيه من الحياة

مستودعك المحلي دفترك، وGitHub نسخة مصوّرة محفوظة في المكتبة. وorigin اسم المكتبة في دفتر عناوينك.

مخطط توضيحي

الأوامر

لا أوامر جديدة بعد. الدرس 5.2 يستخدم git remote وgit push. الشكل 1 يوضح كيف تتبادل النسختان الـ commits.

أخطاء شائعة وحلولها

الظن أن GitHub يتحدّث من تلقاء نفسه.GitHub لا يتغير إلا عند push.
الظن أن origin كلمة خاصة.هو اسم متعارف عليه لـ remote.
نسخ نوع الرابط الخطأ.استخدم رابط HTTPS إن اخترت HTTPS.

تمرين عملي

افتح ملفك في GitHub. اضغط New لبدء مستودع وانظر الخيارات، لكن لا تنشئه بعد. جد خياري Public وPrivate.

النتيجة المتوقعة

تستطيع الإشارة إلى خانة اسم المستودع وخيار الخصوصية.

الإجابات

  • رابط محفوظ إلى مستودع آخر — الـ remote يخزّن رابط مستودع آخر.
  • اسم متعارف عليه للـ remote الرئيسي — هو مجرد اسم.
  • نسخة جهازك من فرع main البعيد — هو remote-tracking branch.

الخلاصة

GitHub يحمل النسخة البعيدة. الـ remote رابط مسمّى، وغالبًا origin. و main فرعك، و origin/main الفرع البعيد المتذكَّر.
