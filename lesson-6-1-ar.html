لوحة التحكم بالمصدر في VS Code

VS Code Source Control

أهداف التعلم

  • أن تفتح عرض Source Control.
  • أن تقرأ حروف الحالة بجانب الملفات.
  • أن تجهّز وتجهّز الكل وتتجاهل التغييرات.
  • أن تكتب رسالة وتنفّذ commit.

المتطلبات المسبقة

الوحدة 4 والمشروع مفتوح في VS Code.

مقدمة

في VS Code أداة Git مدمجة. يعطيك عرض Source Control أزرارًا للأوامر التي تعرفها.

الشرح

افتحه. اضغط أيقونة Source Control في الشريط الأيسر (تشبه فرعًا) أو Ctrl+Shift+G. تظهر شارة برقم الملفات المتغيرة.

الملفات المتغيرة. تظهر تحت Changes. يبيّن الحرف على اليمين الحالة: M معدّل، U غير متتبَّع، A مضاف (ملف جديد مجهّز)، D محذوف. اضغط ملفًا لتفتح مقارنة جنبًا إلى جنب مع آخر commit.

Stage Changes. مرّر المؤشر على ملف واضغط +. يعادل git add file. ينتقل الملف إلى Staged Changes.

Stage All Changes. اضغط + على عنوان Changes. يعادل git add .. افحص القائمة أولًا.

إلغاء التجهيز. اضغط − على ملف مجهّز. يعادل git restore --staged file.

Discard Changes. الزر على شكل سهم بجانب الملف يرمي تعديلاتك في ذلك الملف. تحذير: لا يمكن التراجع. يطلب VS Code تأكيدك.

Commit. اكتب رسالة في الصندوق واضغط Commit. يعادل git commit -m "message". وإن لم يكن شيء مجهّزًا فقد يعرض VS Code تجهيز كل شيء ثم الحفظ. الأفضل أن تجهّز بقصد.

تشبيه من الحياة

Source Control لوحة قيادة السيارة: المحرك نفسه (Git) لكن بأزرار ومؤشرات بدل الأوامر المكتوبة.

مخطط توضيحي

الأوامر

المعادلات: + = git add؛ − = git restore --staged؛ Commit = git commit -m. الشكل 1 يعرض اللوحة مع ثلاثة ملفات متغيرة.

أخطاء شائعة وحلولها

الضغط على Discard بالخطأ.Discard يحذف تعديلاتك. اقرأ رسالة التأكيد بتمعن.
commit برسالة فارغة.يطلب VS Code رسالة. اكتب رسالة واضحة.
عدم ظهور عرض Git.افتح مجلد المشروع نفسه (File ← Open Folder) لا مجلدًا أعلى منه.

تمرين عملي

عدّل index.html وافتح Source Control واضغط الملف لترى المقارنة، وجهّزه بـ + ثم ألغِ تجهيزه بـ −.

النتيجة المتوقعة

ينتقل الملف بين Changes وStaged Changes ويتحدث رقم الشارة.

اختبر فهمك

1. ماذا يعني M بجانب ملف؟
2. أي زر يعادل git add .؟
3. هل يمكن التراجع عن Discard Changes؟

الإجابات

  • معدّل (Modified) — M يشير إلى ملف متتبَّع معدّل.
  • + على عنوان Changes — يجهّز كل تغيير.
  • لا — يزيل تعديلاتك نهائيًا.

الخلاصة

يعرض Source Control الملفات المتغيرة بحروف حالة، ويعطي أزرارًا للتجهيز وإلغائه والتجاهل والـ commit.
