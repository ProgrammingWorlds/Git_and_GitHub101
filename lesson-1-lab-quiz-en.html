Module 1 quiz (pass mark: 70%)

1. What is Git?
2. What is GitHub?
3. What does staging do?
4. After git commit, where are your changes?
5. Can Git work without internet?

Answers

  • A program that tracks file history — Git is the version control program on your computer.
  • A website that hosts Git repositories — GitHub stores remote repositories online.
  • Prepares changes for the next commit — Staging selects the changes for the next commit.
  • In the local repository — Commit saves on your computer; push is the step that uploads.
  • Yes — Git is distributed; the history is local.
