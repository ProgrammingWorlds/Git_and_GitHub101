RESOURCE

Git cheat sheet

Windows · Git Bash · VS Code

Setup

CommandWhat it does
git --versionCheck that Git is installed
git config --global user.name "Your Name"Set your name
git config --global user.email "you@example.com"Set your email (use your GitHub email)
git config --global --listShow your settings

Start

CommandWhat it does
git init -b mainCreate a repository with branch main
git clone URLCopy a remote repository
git statusShow changed, staged and untracked files

Snapshot

CommandWhat it does
git add FILEStage one file
git add .Stage everything in this folder and below
git add -AStage all changes in the whole repository
git commit -m "message"Save a snapshot with a message
git diffShow unstaged changes
git diff --stagedShow staged changes

History

CommandWhat it does
git log --onelineShort history, one line per commit
git show COMMITShow one commit

Branches

CommandWhat it does
git branchList local branches
git switch -c NAMECreate and switch to a branch
git switch NAMESwitch branch
git merge NAMEMerge NAME into the current branch
git merge --abortCancel a conflicted merge
git branch -d NAMEDelete a merged branch

Remote

CommandWhat it does
git remote add origin URLConnect a remote named origin
git remote -vShow remotes
git push -u origin mainFirst push, set upstream
git pushPush to the upstream
git fetchDownload remote changes without merging
git pullFetch and merge

Undo

CommandWhat it does
git restore FILEDiscard edits in a file (irreversible)
git restore --staged FILEUnstage a file
git stash push -m "msg"Set edits aside
git stash popBring stashed edits back
git commit --amend -m "msg"Replace the last commit (not pushed)
git revert COMMITMake a commit that cancels another
git reset --soft HEAD~1Undo last commit, keep staged
git reflogShow where HEAD has been
git rm --cached FILEStop tracking a file, keep it on disk
