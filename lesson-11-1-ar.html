كتابة README بـ Markdown

Writing a README with Markdown

أهداف التعلم

  • أن تكتب أساسيات Markdown.
  • أن تنشئ README.md مفيدًا.
  • أن تعاينه في VS Code.

المتطلبات المسبقة

الوحدة 5.

مقدمة

الـ README هو باب مستودعك. يعرضه GitHub تلقائيًا.

الشرح

Markdown نص عادي برموز بسيطة. # عنوان و## عنوان أصغر و- نقطة و1. بند مرقّم و**bold** نص غامق وعلامة الاقتباس المائلة للكود المضمّن وثلاثة منها لكتلة كود و[text](url) رابط.

README جيد يجيب: ما هذا؟ كيف أشغّله؟ من صنعه؟ الشكل 1 يعرض مثالًا قصيرًا.

أنشئ README.md في جذر المستودع. في VS Code اضغط Ctrl+Shift+V للمعاينة.

احفظه: git add README.md وgit commit -m "Improve README" وgit push.

في GitHub يظهر الـ README تحت قائمة الملفات في صفحة المستودع.

اجعله قصيرًا ودقيقًا ومحدّثًا.

تشبيه من الحياة

الـ README لافتة فوق باب المتجر: تخبر الزائر بما في الداخل قبل أن يدخل.

مخطط توضيحي

الأوامر

git add README.md
git commit -m "Improve README"
git push

الشكل 1 يعرض README صغيرًا.

أخطاء شائعة وحلولها

README فارغ.أضف عنوانًا ووصفًا على الأقل.
تنسيق مكسور لغياب أسطر فارغة.اترك سطرًا فارغًا بين الكتل.
تعليمات قديمة.حدّثه عند تغيّر المشروع.

تمرين عملي

اكتب README خاصًا بك فيه عنوان وميزات وطريقة تشغيل ومؤلف.

النتيجة المتوقعة

يعرض GitHub عناوين منسّقة ورابطًا.

الإجابات

  • عنوانًا — كثرة # تصغّر العنوان.
  • Ctrl+Shift+V — يفتح المعاينة.
  • جذر المستودع — يعرض GitHub README الجذر.

الخلاصة

الـ README يشرح ماذا وكيف ومن، ويُكتب بـ Markdown.
