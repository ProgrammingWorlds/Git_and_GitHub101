المصطلحات

المصطلحالمعنى
Repositoryمجلد مشروع يتتبعه Git مع تاريخه.
Commitلقطة محفوظة للتغييرات المجهّزة مع رسالة.
Staging areaالمكان الذي تختار فيه تغييرات الـ commit القادم.
Working directoryالملفات التي تراها وتعدّلها.
Branchمؤشر متحرك إلى commit.
mainاسم الفرع الافتراضي في هذا الكورس.
HEADمؤشر إلى الفرع أو الـ commit الذي أنت عليه.
Mergeدمج فرع في آخر.
Fast-forwardدمج يتم بتحريك وسم الفرع للأمام.
Merge conflictتغيير الأسطر نفسها بشكلين؛ عليك الاختيار.
Remoteنسخة من المستودع مستضافة في مكان آخر مثل GitHub.
originالاسم الافتراضي للـ remote الرئيسي.
Upstreamالفرع البعيد الذي يتتبعه فرعك المحلي.
Pushرفع commits محلية إلى remote.
Pullجلب commits بعيدة ودمجها.
Fetchتنزيل commits بعيدة دون دمج.
Cloneنسخ مستودع بعيد إلى جهازك.
Forkنسختك على GitHub من مستودع غيرك.
Pull request (PR)اقتراح لدمج فرع مع مراجعة.
Issueمهمة أو خطأ أو فكرة تُتابَع في GitHub.
Tracked fileملف يعرفه Git أصلًا.
Untracked fileملف جديد لا يتتبعه Git بعد.
.gitignoreملف يسرد أنماطًا يتجاهلها Git.
READMEملف يعرّف بالمشروع.
Markdownلغة تنسيق نصوص بسيطة.
Stashتخزين مؤقت للتعديلات غير المحفوظة.
Revertcommit يلغي commit سابقًا.
Resetنقل فرع إلى commit آخر.
Reflogسجل محلي لأماكن HEAD السابقة.
Detached HEADHEAD على commit لا على فرع.
HTTPSبروتوكول الويب الذي يستخدمه الكورس مع GitHub.
Git Credential Managerأداة Windows تسجّل دخولك إلى GitHub.
Tokenسر يُستخدم للمصادقة.
2FAإثبات هوية ثانٍ عند الدخول.
GitHub Pagesاستضافة ثابتة مجانية من مستودع.
Source Controlلوحة Git في VS Code.
Sync Changesزر في VS Code: pull ثم push.
Diffالفرق بين نسختين.
Version controlتسجيل التغييرات لمراجعتها واستعادتها.
