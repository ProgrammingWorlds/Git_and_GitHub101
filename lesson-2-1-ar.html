تثبيت Git وVS Code

Installing Git and VS Code

أهداف التعلم

  • أن تثبّت Git على ويندوز.
  • أن تثبّت Visual Studio Code.
  • أن تفتح الطرفية المدمجة وتختار Git Bash.
  • أن تتحقق من التثبيت بالأمر git --version.

المتطلبات المسبقة

الوحدة 1، وحاسوب ويندوز واتصال بالإنترنت.

مقدمة

قبل أن يعمل أي أمر يجب أن تكون الأدوات على جهازك. هذا الدرس يثبّت الاثنين ثم يتأكد أن Git يستجيب.

الشرح

تثبيت Git. افتح git-scm.com واختر Download for Windows. شغّل المثبّت. الخيارات الافتراضية آمنة للمبتدئين. يمكنك اختيار Visual Studio Code محررًا افتراضيًا، واختيار main اسمًا للفروع الجديدة إن عرض المثبّت ذلك. اضغط Next حتى Install ثم Finish.

التحقق. افتح Git Bash من قائمة ابدأ ونفّذ git --version. إن ردّ Git برقم إصدار فهو مثبّت.

تثبيت VS Code. افتح code.visualstudio.com ونزّل مثبّت ويندوز وشغّله. أبقِ خيار Add to PATH مفعّلًا.

فتح الطرفية في VS Code. من القائمة Terminal ← New Terminal أو اضغط Ctrl+`. في لوحة الطرفية اضغط السهم بجانب + واختر Git Bash.

تشبيه من الحياة

تثبيت الأدوات كتجهيز المطبخ قبل الطبخ: لا يوجد طعام بعد، لكن كل وصفة في هذه الدورة تحتاج هذه الأدوات.

مخطط توضيحي

الأوامر

نفّذ هذا في Git Bash أو طرفية VS Code. الخيار --version يطلب من البرنامج طباعة إصداره ثم الخروج.

git --version

أخطاء شائعة وحلولها

«git is not recognized»أغلق الطرفية وافتحها من جديد. وإن استمر الخطأ فأعد تشغيل مثبّت Git.
فتح PowerShell وتوقع أوامر Bash.اختر Git Bash من قائمة ملفات تعريف الطرفية.
تعطيل Add to PATH عند تثبيت VS Code.أعد تشغيل المثبّت وفعّله.

تمرين عملي

ثبّت Git وVS Code، وافتح طرفية داخل VS Code، واختر Git Bash، ونفّذ git --version.

النتيجة المتوقعة

تطبع الطرفية سطرًا يبدأ بـ git version.

اختبر فهمك

1. أي أمر يتحقق من تثبيت Git؟
2. أي طرفية نستخدم في هذه الدورة؟
3. أي اختصار يفتح طرفية في VS Code؟

الإجابات

  • git --version — git --version يطبع الإصدار المثبّت.
  • Git Bash — Git Bash يعطينا الأوامر نفسها على ويندوز.
  • Ctrl+` — الاختصار Ctrl+` يفتح الطرفية المدمجة ويغلقها.

الخلاصة

ثبّتّ Git وVS Code، وفتحت طرفية في VS Code، واخترت Git Bash، وتأكدت أن Git يعمل.
