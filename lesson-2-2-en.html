MODULE 02 · LESSON 2.2

Creating your GitHub account

إنشاء حساب GitHub

Learning objectives

  • Create and verify a GitHub account.
  • Find your way around the dashboard.
  • Secure the account with two-factor authentication.
  • Name the ways Git signs in to GitHub.

Prerequisites

Lesson 2.1 and an email address you can open.

Introduction

Your GitHub account is your identity online. Your projects, your history and your future portfolio live there, so we protect it from day one.

Explanation

Create the account. Go to github.com and choose Sign up. Enter your email, a strong password and a username. Choose a username you would be happy to show an employer.

Verify your email. GitHub sends a code to your email. Enter it to finish. You may also be asked to solve a short puzzle.

The dashboard. After sign-in you see your repositories, activity and suggestions. Your avatar (top right) opens the menu with Your profile, Your repositories and Settings.

Profile. Add a photo and a short bio. Keep personal details you do not want public out of it.

Security. Use a unique password in a password manager. In Settings → Password and authentication enable two-factor authentication (2FA) with an authenticator app, and save the recovery codes somewhere safe.

How Git signs in. Over HTTPS, Git asks for your GitHub login through a sign-in window and keeps it in Git Credential Manager (included with Git for Windows). With SSH, you add a key pair to your account. Never use your GitHub password as a Git password in the terminal. You will set up a method in Module 5.

Real-world analogy

Your account is like a bank account for your code: a strong password and a second lock (2FA) keep it yours.

Common mistakes and solutions

Losing the 2FA recovery codes.Store them in a password manager or print them.
Using a private email in public commits.Later you can use the GitHub “noreply” address (Lesson 2.3).
Choosing a joke username.Pick a professional one. It becomes part of your URLs.

Practical exercise

Create your account, verify the email, add a profile photo, and turn on 2FA.

Expected result

You can open your profile at github.com/your-username and Settings shows 2FA as enabled.

Knowledge check

1. Why enable 2FA?
2. Where do your projects live online?
3. Name one way Git signs in to GitHub.

Answers

  • A second check protects the account — 2FA stops access with only a stolen password.
  • GitHub — GitHub hosts your remote repositories.
  • SSH keys — HTTPS with Credential Manager and SSH keys are the two common methods.

Summary

You created and secured a GitHub account and learned the two sign-in methods Git uses: HTTPS and SSH.
