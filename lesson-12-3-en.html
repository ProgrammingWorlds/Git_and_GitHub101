Learning objectives

  • Verify the live URL.
  • Submit the project.

Prerequisites

Lesson 12.2.

Introduction

GitHub Pages hosts your static site for free from a repository.

Explanation

On GitHub open the repository, then Settings → Pages.

Under Build and deployment, set Source to Deploy from a branch, choose main and / (root), and click Save.

Wait one or two minutes and refresh. GitHub shows the address: https://YOUR-USERNAME.github.io/portfolio-website/.

Open the address and check all links and the CSS. Paths must be relative, such as style.css.

Make a fix by branch and PR; after you merge, the site updates automatically within minutes.

Submit: repository URL, live URL, and a short note listing your branches and PRs. Check the rubric before you submit.

GitHub Pages on a free account requires a public repository. Check current GitHub plan limits if you need a private one.

Real-world analogy

Publishing is opening the shop doors: the work you did behind the scenes is now visible.

Knowledge check

1. Where do you enable Pages?
2. Which file must be in the root?
3. What do you submit?

Answers

  • Settings → Pages — It is a repository setting.
  • index.html — It is the home page.
  • Repo URL and live URL — Plus a short note.

Summary

Enable Pages from main/root, verify the live URL, and submit both URLs.
