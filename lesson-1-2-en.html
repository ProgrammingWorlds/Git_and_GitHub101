Git vs GitHub vs VS Code

Git مقابل GitHub مقابل VS Code

Learning objectives

  • Define Git, GitHub and VS Code in one sentence each.
  • Explain local and remote repositories.
  • Tell public repositories from private ones.

Prerequisites

Lesson 1.1.

Introduction

Beginners often use “Git” and “GitHub” as if they were one thing. They are three different tools that work together, and knowing the difference removes most early confusion.

Explanation

Git is a free program on your computer. It records the history of your files. It works without internet.

GitHub is a website that stores Git projects online. It adds sharing and teamwork: backups, issues, pull requests and a profile page.

VS Code (Visual Studio Code) is a code editor. It has Git built in, so you can stage, commit and push with buttons instead of typing.

A repository (repo) is a project folder plus its Git history. Your copy is the local repository. The copy on GitHub is the remote repository. A commit is one saved snapshot, and a branch is a line of commits. You will study branches in Module 7.

Public repositories can be seen by anyone. Private repositories are visible only to you and people you invite. Never put passwords in either kind.

Real-world analogy

Writing a book: VS Code is your writing desk, Git is the editor who keeps every draft, and GitHub is the shared cloud folder your team reads.

Common mistakes and solutions

Thinking GitHub is required to use Git.Git works alone. GitHub is optional, but very useful for sharing.
Thinking VS Code and Git are the same.VS Code is an editor. It only gives you buttons for Git.
Making a repo public by accident.Check the visibility setting before you create or publish a repository.

Practical exercise

Open github.com in your browser. Open any public repository. Find three things: the README text, the list of files, and the branch name (usually main).

Expected result

You can point to the README, the file list and the branch selector on the page. You did not need an account for this.

Knowledge check

1. Which tool stores your project online?
2. Where is the local repository?
3. Who can see a private repository?

Answers

  • GitHub — GitHub hosts remote repositories.
  • On your computer — The local repository is the project history stored on your own machine.
  • Only you and people you invite — Private means visible only to you and chosen collaborators.

Summary

Git tracks changes, GitHub hosts repositories online, and VS Code is the editor with Git buttons. Your computer holds the local repository, GitHub holds the remote one.
