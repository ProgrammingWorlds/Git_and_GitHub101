فهم المستودعات

Understanding repositories

أهداف التعلم

  • أن تعرّف المستودع.
  • أن تفرّق بين مجلد المشروع ومستودع Git.
  • أن تشرح ما يحتويه مجلد .git.
  • أن تفرّق بين المستودع المحلي والبعيد.

المتطلبات المسبقة

إكمال الوحدة 2.

مقدمة

سمعت كلمة «مستودع» مرات كثيرة. هنا تأخذ معنى دقيقًا، وسترى بالضبط ما الذي يجعل المجلد خاصًا بالنسبة إلى Git.

الشرح

المستودع (Repository) مجلد مشروع يتتبّعه Git مع التاريخ الكامل لذلك المشروع.

المجلد العادي مجرد ملفات. ويصبح مستودع Git عندما تنفّذ git init داخله، فينشئ Git مجلدًا مخفيًا اسمه .git.

مجلد .git يخزّن الـ commits والفروع وإعدادات المستودع. أما ملفاتك فتوجد بجانبه لا داخله. لا تعدّل .git ولا تحذفه يدويًا. حذفه يزيل التاريخ مع بقاء ملفاتك.

المستودع المحلي هو الموجود على جهازك. والمستودع البعيد نسخة على خادم مثل GitHub. ستربطهما في الوحدة 5.

لإظهار العناصر المخفية في ويندوز افتح مستكشف الملفات واختر View ← Show ← Hidden items.

تشبيه من الحياة

المجلد بيت، ومجلد .git أرشيف تسجيلات كاميرات المراقبة: يبقى البيت كما هو، لكن الأرشيف يتذكر كل ما حدث داخله.

مخطط توضيحي

الأوامر

في Git Bash الأمر ls -a يعرض كل الملفات بما فيها المخفية. داخل المستودع سترى .git.

ls -a

أخطاء شائعة وحلولها

حذف مجلد .git.يضيع التاريخ. افعل ذلك فقط إن أردت فعلًا التوقف عن استخدام Git في المشروع.
الظن أن .git داخل ملفات مشروعك.هو مجلد مخفي بجانب ملفاتك، وملفاتك خارجه.
إنشاء مستودع داخل مستودع آخر.تأكد أنك في المجلد الصحيح قبل git init.

تمرين عملي

فعّل العناصر المخفية في مستكشف الملفات. افتح مجلد Documents وتأكد أنه لا يحتوي مجلد .git.

النتيجة المتوقعة

لا ترى مجلد .git. المجلدات العادية ليست مستودعات حتى تهيّئها (الدرس 3.2).

الإجابات

  • وجود مجلد .git مخفي داخله — الأمر git init ينشئ .git الذي يحتوي التاريخ.
  • الـ commits والفروع والإعدادات — يحتوي بيانات المستودع.
  • على خادم مثل GitHub — البعيد يعني نسخة مستضافة في مكان آخر.

الخلاصة

المستودع هو مجلد مشروع مع تاريخ Git المخزّن في مجلد .git المخفي. المحلي على جهازك، والبعيد على خادم مثل GitHub.
