MODULE 05 · LESSON 5.1

Local vs remote repositories

المستودع المحلي مقابل البعيد

Learning objectives

  • Explain what a GitHub repository is.
  • Read a remote URL.
  • Explain what origin means.
  • Tell main from origin/main.
  • Tell HTTPS from SSH URLs.

Prerequisites

Module 4 and your GitHub account.

Introduction

So far your history lives only on your computer. GitHub holds a second copy online. This lesson explains how the two copies relate before you connect them.

Explanation

A GitHub repository is the remote copy of your project. It stores the same commits you have locally, and adds a web page, sharing and teamwork tools.

A remote is a saved bookmark to another repository. Its URL says where it lives. The HTTPS form is https://github.com/USER/REPO.git. The SSH form is git@github.com:USER/REPO.git.

origin is only a name. By convention Git calls the main remote origin. You could name it differently, but everyone uses origin.

Branches. main is your local branch. origin/main is your computer’s remembered copy of the remote’s main branch (a remote-tracking branch). It updates only when you push, fetch or pull.

HTTPS or SSH? HTTPS is simpler for beginners: Git Credential Manager signs you in through the browser. SSH uses a key pair and no password prompts after setup. This course uses HTTPS.

Real-world analogy

Your local repo is your notebook. GitHub is the photocopy kept at the library. origin is the library’s name on your address list.

Knowledge check

1. What is a remote?
2. What does origin mean?
3. What is origin/main?

Answers

  • A saved link to another repository — A remote stores the URL of another repository.
  • A conventional name for the main remote — It is just a name.
  • Your computer’s copy of the remote main branch — It is a remote-tracking branch.

Summary

GitHub holds the remote copy. A remote is a named URL, usually origin. main is your branch; origin/main is the remembered remote one.

Key vocabulary
