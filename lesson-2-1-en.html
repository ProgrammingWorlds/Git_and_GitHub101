Installing Git and VS Code

تثبيت Git وVS Code

Learning objectives

  • Install Git on Windows.
  • Install Visual Studio Code.
  • Open the integrated terminal and choose Git Bash.
  • Verify the installation with git --version.

Prerequisites

Module 1. A Windows computer and an internet connection.

Introduction

Before any command works, the tools must be on your computer. This lesson installs both, then checks that Git answers.

Explanation

Install Git. Go to git-scm.com and choose Download for Windows. Run the installer. The default options are safe for beginners. You may choose Visual Studio Code as the default editor, and choose main as the name for new branches if the installer offers it. Click Next until Install, then Finish.

Verify. Open Git Bash from the Start menu and run git --version. If Git answers with a version number, it is installed.

Install VS Code. Go to code.visualstudio.com, download the Windows installer and run it. Keep Add to PATH enabled.

Open the terminal in VS Code. Use the menu Terminal → New Terminal, or press Ctrl+`. In the terminal panel, use the dropdown arrow next to the + and choose Git Bash as the profile.

Real-world analogy

Installing tools is like stocking a kitchen before you cook: nothing to cook yet, but every recipe in this course needs these tools.

Common mistakes and solutions

“git is not recognized”Close and reopen the terminal. If it still fails, run the Git installer again.
Opening PowerShell and expecting Bash commands.Choose Git Bash in the terminal profile list.
Skipping Add to PATH for VS Code.Re-run the installer and enable it.

Practical exercise

Install Git and VS Code, open a terminal inside VS Code, select Git Bash, and run git --version.

Expected result

The terminal prints a line starting with git version.

Knowledge check

1. Which command checks the Git installation?
2. Which terminal do we use in this course?
3. Which shortcut opens a terminal in VS Code?

Answers

  • git --version — git --version prints the installed version.
  • Git Bash — Git Bash gives us the same commands on Windows.
  • Ctrl+` — Ctrl+` toggles the integrated terminal.

Summary

You installed Git and VS Code, opened a terminal in VS Code, chose Git Bash, and confirmed Git works.
