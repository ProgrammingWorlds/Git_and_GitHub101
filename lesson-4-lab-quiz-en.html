Module 4 quiz (pass mark: 70%)

1. Which command stages one file?
2. What does git add . do?
3. Which command saves staged changes?
4. How do you see staged changes?
5. What does (HEAD -> main) mean in the log?

Answers

  • git add index.html — git add followed by the file name stages it.
  • Stages changes in the current folder — It stages; it does not commit or push.
  • git commit -m "message" — commit creates the snapshot.
  • git diff --staged — --staged compares the staging area with the last commit.
  • You are on the latest commit of main — HEAD marks your current position.
