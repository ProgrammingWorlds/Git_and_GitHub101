الإجابات

  • برنامج يتتبّع تاريخ الملفات — Git هو برنامج التحكم بالإصدارات على جهازك.
  • موقع يستضيف مستودعات Git — GitHub يحفظ المستودعات البعيدة على الإنترنت.
  • تحضّر التغييرات للـ commit القادم — التجهيز يحدد التغييرات التي ستدخل الـ commit القادم.
  • في المستودع المحلي — الـ commit يحفظ على جهازك، والرفع خطوة منفصلة.
  • نعم — Git موزّع، والتاريخ محلي.
