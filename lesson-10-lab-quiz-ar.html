الوحدة 10

المختبر العملي 10 · تراجع بأمان

  1. عدّل index.html ونفّذ git restore index.html. تأكد أن التعديل اختفى.
  2. عدّل style.css ونفّذ git add style.css ثم git restore --staged style.css. تحقق بـ git status. ثم استعده.
  3. أنشئ test.txt واحفظه Add test file ثم نفّذ git commit --amend -m "Add test file for practice".
  4. نفّذ git revert HEAD --no-edit.
  5. أنشئ commit آخر ثم git reset --soft HEAD~1 وأعد حفظه.
  6. نفّذ git reflog وابحث عن commits.
الفحصينجح إذا…
Restoreرُميت التعديلات كما هو متوقع
Amend/revertيعرض السجل commit الـ revert
Reset/reflogأعدت الحفظ ووجدته في reflog
معيار التقييم: 3 من 3 = نجاح.

اختبار الوحدة 10 (علامة النجاح: 70%)

1. أي أمر يرمي تعديلات ملف؟
2. أيهما آمن للـ commits المرفوعة؟
3. reset --soft يُبقي التغييرات…
4. كيف تجد commit ضائعًا؟
5. الرفع يقول «fetch first». ماذا تفعل؟

الإجابات

  • git restore FILE — لا رجعة فيه.
  • git revert — يضيف commit جديدًا.
  • في staging — تبقى في staging.
  • git reflog — يتتبع HEAD.
  • git pull ثم push — احصل على الأحدث أولًا.
