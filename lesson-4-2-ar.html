فهم git commit

Understanding git commit

أهداف التعلم

  • أن تشرح ما هو الـ commit.
  • أن تنشئ commit برسالة جيدة.
  • أن تقرأ commit hash.
  • أن تفرّق بين الرسائل الجيدة والسيئة.

المتطلبات المسبقة

الدرس 4.1.

مقدمة

الـ commit هو اللحظة التي تحفظ فيها لقطة في التاريخ. هذا قلب Git.

الشرح

الـ commit لقطة من التغييرات المجهّزة مع رسالة واسم صاحبها وتاريخ. يُخزَّن في تاريخك المحلي ويرتبط بالـ commit الذي قبله.

الأمر git commit -m "Add homepage" ينشئ commit بهذه الرسالة. الخيار -m يعني «رسالة». ضع الرسالة بين علامتي اقتباس.

يطبع Git سطرًا مثل [main (root-commit) 3f2a9c1] Add homepage. main هو الفرع، وroot-commit يدل على أول commit في المستودع، و3f2a9c1 بداية commit hash وهو معرّف فريد.

تبقى الـ commits على جهازك. لا شيء على GitHub حتى تنفّذ push (الوحدة 5).

الرسائل الجيدة تبدأ بفعل وتقول ما الذي تغيّر: Add homepage وFix navigation styling وUpdate README. الرسائل السيئة لا تقول شيئًا: changes وstuff وasdf.

commits ذات معنى. يجب أن يمثل كل commit تغييرًا منطقيًا واحدًا يعمل. هذا يجعل التاريخ مقروءًا والتراجع عن الأخطاء سهلًا.

تشبيه من الحياة

الـ commit نقطة حفظ في لعبة فيديو مع تسمية. التسميات الجيدة تساعدك على إيجاد «قبل المعركة الأخيرة» بسرعة.

مخطط توضيحي

الأوامر

git commit -m "Add homepage"
git commit -m "Fix navigation styling"
git commit -m "Update README"

الخيار: -m الرسالة. نفّذه بعد التجهيز فقط. الشكل 1 يعرض أول commit في المشروع.

أخطاء شائعة وحلولها

«Author identity unknown»اضبط user.name وuser.email (الدرس 2.3).
«nothing to commit»لا شيء مجهّز. نفّذ git add أولًا.
نسيان علامتي الاقتباس.ضع الرسالة بين علامتي اقتباس مزدوجتين.

تمرين عملي

احفظ index.html وstyle.css المجهّزين في commit برسالة Add homepage.

النتيجة المتوقعة

يطبع Git سطرًا يبدأ بـ [main (root-commit) ويسرد ملفين أُنشئا، كما في الشكل 1.

اختبر فهمك

1. ماذا يعني -m في git commit -m؟
2. أيّ هذه رسالة جيدة؟
3. أين يوجد الـ commit الجديد؟

الإجابات

  • رسالة (Message) — يعطي رسالة الـ commit.
  • Add homepage — تبدأ بفعل وتقول ما الذي تغيّر.
  • على جهازك — الـ push هو الخطوة التي ترفعه.

الخلاصة

الـ commit يحفظ التغييرات المجهّزة مع رسالة. استخدم رسائل واضحة، وتذكّر أن الـ commits محلية حتى تنفّذ push.
