Module 3 quiz (pass mark: 70%)

1. Which command creates a repository?
2. What does .git contain?
3. What does git status show first?
4. A new file shows as…
5. Why save files before git status?

Answers

  • git init — git init initializes a repository.
  • The repository history and settings — It is the repository database.
  • The current branch — The first line names the branch.
  • Untracked — Git has not tracked it yet.
  • Git only sees saved changes — Unsaved edits are not on disk.
