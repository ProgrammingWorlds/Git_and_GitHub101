MODULE 06 · LESSON 6.3

Branches and history in VS Code

الفروع والتاريخ في VS Code

Learning objectives

  • Read the branch indicator.
  • Create and switch branches.
  • View file history.
  • Know where conflicts and sign-in live.
  • Tell built-in Git from GitLens.

Prerequisites

Lesson 6.2.

Introduction

Branches are covered in depth in Module 7. Here you only learn where the controls live.

Explanation

Branch indicator. The bottom-left of the window shows the current branch, such as main.

Switch or create. Click it. A list opens at the top: choose a branch to switch, or choose Create new branch… and type a name such as feature/homepage.

History. In the Explorer view, open the Timeline panel at the bottom to see the commits that changed the open file. Click one to compare. Recent versions also offer a graph of commits inside Source Control.

Compare changes. Click any changed file in Source Control to see old and new side by side.

Conflicts. If a merge conflicts, files appear under Merge Changes. Open one and use Resolve in Merge Editor. Module 7 teaches this.

Sync Changes pulls then pushes in one click.

GitHub sign-in. The Accounts icon at the bottom of the left bar shows who is signed in and lets you sign in or out.

GitLens is an optional extension that adds blame, richer history and more. It is not needed for this course. Everything above is built in.

Real-world analogy

The status bar is a car’s road sign: it always tells you which road (branch) you are on.

Diagram

Commands

Equivalents: git branch shows the branch; git switch -c feature/homepage creates one; git switch main switches.

Common mistakes and solutions

Editing on main by accident.Look at the bottom-left before you start.
Switch blocked by changes.Commit your changes first.
Installing GitLens and getting lost.Learn the built-in tools first.

Practical exercise

Create a branch feature/homepage from the status bar, then switch back to main.

Expected result

The status bar shows feature/homepage, then main again.

Knowledge check

1. Where do you see the current branch?
2. Is GitLens required?
3. Where do you sign in to GitHub?

Answers

  • Bottom-left status bar — It is shown in the status bar.
  • No, it is optional — Git is built into VS Code.
  • The Accounts icon — Accounts manages sign-in.

Summary

Branch controls live in the status bar, history in Timeline, conflicts in the Merge Editor, and sign-in under Accounts.
