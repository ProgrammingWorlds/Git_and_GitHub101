MODULE 08 · LESSON 8.1

Cloning a repository

نسخ مستودع

Learning objectives

  • Explain what clone does.
  • Clone with HTTPS.
  • Choose a folder.
  • Verify with git remote -v.

Prerequisites

Module 5 and a GitHub repository.

Introduction

Cloning gives you a full local copy of a repository, including its whole history.

Explanation

git clone downloads the repository, creates a folder, and sets up the remote named origin for you. You do not need git init or git remote add.

On GitHub, open the repository, click the green Code button, choose HTTPS, and copy the URL.

Open Git Bash in the folder where you want the project, for example Documents.

Run git clone URL. Git creates a folder with the repository name.

cd my-first-project, then git remote -v to see origin. git log --oneline shows the history you received.

In VS Code: Source Control → Clone Repository, paste the URL, choose a parent folder, and click Open when asked.

A private repository asks you to sign in. Git Credential Manager opens a browser window for that.

Real-world analogy

Cloning is photocopying an entire notebook, including every page ever written, and getting a pointer back to the original.

Diagram

Commands

git clone https://github.com/YOUR-USERNAME/my-first-project.git
cd my-first-project
git remote -v

Common mistakes and solutions

Cloning inside a folder that is already a repository.Pick a normal folder such as Documents.
“Repository not found”Check the URL and that you are signed in to the right account.
Using the wrong folder name afterwards.Run cd into the cloned folder before other commands.

Practical exercise

Clone your repository into a new folder next to the original and compare the two.

Expected result

The clone has the same files and git log --oneline shows the same commits.

Knowledge check

1. What does clone create?
2. Which URL type does this course use?
3. Do you need git init after clone?

Answers

  • A local copy with history and origin — It copies everything.
  • HTTPS — HTTPS with Credential Manager.
  • No — Clone already creates the repository.

Summary

Clone copies a repository, with history, and sets origin for you.
