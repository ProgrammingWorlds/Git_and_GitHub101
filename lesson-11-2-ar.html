تجاهل الملفات بـ .gitignore

Ignoring files with .gitignore

أهداف التعلم

  • أن تشرح .gitignore.
  • أن تكتب أنماطًا.
  • أن توقف تتبع ملف سبق حفظه.

المتطلبات المسبقة

الدرس 11.1.

مقدمة

بعض الملفات يجب ألا تدخل Git أبدًا: الأسرار والسجلات وملفات النظام والاعتماديات المنزّلة.

الشرح

.gitignore ملف نصي في جذر المستودع. كل سطر نمط لملفات يتجاهلها Git (الشكل 1).

أنماط شائعة: .env و*.log (أي ملف log) وnode_modules/ (مجلد) وThumbs.db و.DS_Store.

الأسطر التي تبدأ بـ # تعليقات. والعلامة ! في البداية تعيد تضمين ملف.

أنشئ الملف واحفظه وشاركه مع الفريق ليتجاهل الجميع الأشياء نفسها.

مهم: الـ .gitignore يؤثر فقط في ملفات لا يتتبعها Git بعد. إن كنت حفظت ملفًا فنفّذ git rm --cached FILE ثم commit. يبقى الملف على قرصك ويخرج من الـ commits القادمة.

إن كان سرًّا فالتجاهل لا يكفي؛ هو ما زال في التاريخ (الدرس 11.3).

تحقق بـ git status أن الملفات المتجاهلة لم تعد تظهر.

تشبيه من الحياة

الـ .gitignore قائمة «لا تصوّر» لكاميرا تصوّر كل شيء عدا ذلك.

مخطط توضيحي

الأوامر

git rm --cached FILE
git status

الشكل 1 يعرض تجاهل ملف سري.

أخطاء شائعة وحلولها

توقّع أن .gitignore يوقف تتبع ملف محفوظ.استخدم git rm --cached.
اسم ملف خاطئ مثل gitignore.txt.يجب أن يكون .gitignore بلا امتداد.
تجاهل أكثر من اللازم.اجعل الأنماط محددة.

تمرين عملي

أنشئ .env بقيمة وهمية وتجاهله وتأكد أن status لا يعرضه.

النتيجة المتوقعة

يعرض git status الملف .gitignore دون .env.

اختبر فهمك

1. أين يقع .gitignore؟
2. هل يوقف .gitignore تتبع ملفات محفوظة؟
3. ماذا يطابق *.log؟

الإجابات

  • جذر المستودع — عادةً في الجذر.
  • لا — استخدم git rm --cached.
  • كل ملفات .log — * رمز بدل.

الخلاصة

اكتب الأنماط في .gitignore، واستخدم git rm --cached للملفات المتتبَّعة أصلًا.
