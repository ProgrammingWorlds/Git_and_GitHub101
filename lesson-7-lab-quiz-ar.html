المختبر العملي 7 · أنشئ فرعًا وادمجه وحلّ تعارضًا

  1. تأكد أن git status نظيف على main.
  2. git switch -c feature/homepage. غيّر سطر العنوان إلى <h1>Welcome to my site</h1>. احفظ: Update heading on feature branch.
  3. git switch main. غيّر السطر نفسه إلى <h1>Hello, World!</h1>. احفظ: Update heading on main.
  4. نفّذ git merge feature/homepage. يظهر تعارض.
  5. افتح index.html وأبقِ <h1>Welcome to my site</h1> وأزل كل العلامات.
  6. git add index.html ثم git commit. احذف الفرع بـ git branch -d feature/homepage.

الإجابات

  • git branch — النجمة تدل على الحالي.
