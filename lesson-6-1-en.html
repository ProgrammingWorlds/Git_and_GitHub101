MODULE 06 · LESSON 6.1

VS Code Source Control

لوحة التحكم بالمصدر في VS Code

Learning objectives

  • Open the Source Control view.
  • Read the status letters beside files.
  • Stage, stage all and discard changes.
  • Write a commit message and commit.

Prerequisites

Module 4 and the project open in VS Code.

Introduction

VS Code has Git built in. The Source Control view gives you buttons for the commands you already know.

Explanation

Open it. Click the Source Control icon in the left bar (it looks like a branch) or press Ctrl+Shift+G. A number badge shows how many files changed.

Changed files. Files appear under Changes. A letter on the right shows the status: M modified, U untracked, A added (staged new file), D deleted. Click a file to open a side-by-side comparison with the last commit.

Stage Changes. Hover over a file and click +. This equals git add file. The file moves to Staged Changes.

Stage All Changes. Click + on the Changes heading. This equals git add .. Check the list first.

Unstage. Click − on a staged file. This equals git restore --staged file.

Discard Changes. The arrow-shaped button beside a file throws away your edits in that file. Warning: this cannot be undone. VS Code asks you to confirm.

Commit. Type a message in the box and click Commit. This equals git commit -m "message". If nothing is staged, VS Code may offer to stage everything and commit. Prefer to stage deliberately.

Real-world analogy

Source Control is the dashboard of a car: the same engine (Git), but with buttons and gauges instead of typed instructions.

Common mistakes and solutions

Clicking Discard by accident.Discard deletes your edits. Read the confirmation carefully.
Committing with an empty message.VS Code requires a message. Write a clear one.
Not seeing the Git view.Open the project folder itself (File → Open Folder), not a parent folder.

Practical exercise

Edit index.html, open Source Control, click the file to see the comparison, stage it with +, then unstage it with −.

Expected result

The file moves between Changes and Staged Changes, and the badge number updates.

Knowledge check

1. What does M mean beside a file?
2. Which button equals git add .?
3. Can Discard Changes be undone?

Answers

  • Modified — M marks a modified tracked file.
  • + on the Changes heading — It stages every change.
  • No — It permanently removes unsaved-to-Git edits.

Summary

Source Control shows changed files with status letters and gives buttons to stage, unstage, discard and commit.
