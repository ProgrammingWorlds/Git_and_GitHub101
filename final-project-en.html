CAPSTONE

Final project and rubric

Brief

Build a one-page portfolio website with Home, About, Projects and Contact sections using plain HTML and CSS. Manage it with Git and GitHub like a team project and publish it with GitHub Pages.

Requirements

  • Repository named portfolio-website with index.html, style.css, README.md and .gitignore.
  • At least 8 commits with specific messages.
  • At least 3 feature branches and 2 merged pull requests with descriptions.
  • No secrets in the repository.
  • Live GitHub Pages URL.

Starter and solution

Starter files: final-project/starter. A sample solution: final-project/solution. Use the solution only to compare after you finish.
